## 📌 项目定位与核心价值

本项目是一套**软硬件协同的本地业务自动化服务中枢与 AI Agent 赋能体系**。

项目始于商业实体运营中的两大典型业务痛点：
1. **停车券领券痛点**：第三方系统生成的优惠码为“一次性动态码”（即扫即销，无法打印贴墙）且容易产生并发抢码冲突；
2. **会员办卡流程繁杂**：人工录入会员信息、人脸核验、选择卡种、填写顾问、审核再到各渠道支付步骤冗长低效。

系统不仅实现了底层的高性能 Python 自动化微服务与 Electron 桌面客户端，更**开创性地封装了标准化 AI Agent Skill 协议**，使 **WorkBuddy 等第三方智能体平台** 能够直接通过自然语言指挥本地自动化服务完成复杂的办卡与业务流转。

## 🤖 亮点聚焦：AI Agent Skill 体系化封装（WorkBuddy 接入）

为将本地自动化能力赋能给生成式 AI 智能体，设计了结构严谨的 **会员办卡 Agent Skill**（符合标准 Agent 技能协议规范）：

```
[用户自然语言交互]
       │  "帮张三办理一张尊享年卡，金额 1999，微信支付..."
       ▼
[第三方 Agent 平台 (如 WorkBuddy / Claude / 本地智能体)]
       │  读取导出的 SKILL.md 规范与动态本机连接凭据
       ▼
[Agent 安全调用网关]
  ├─ 密钥鉴权 (X-Api-Key)
  ├─ 代理隔离 (强制直连本机，杜绝网络代理干扰)
  └─ 关键节点二次明确授权确认 (防止 AI 幻觉误扣费)
       ▼
[本地自动化后端服务 (Python / FastAPI)]
  ├─ 1. 查询会员与卡种 (GET /api/v1/card/users, /cards) -> 无档案则自动建档
  ├─ 2. 人像二进制上传与人脸检测 (POST /api/v1/card/photo)
  ├─ 3. 生成 10 分钟有效草稿预订单 (POST /api/v1/card/prepare)
  ├─ 4. 正式下单与订单审核 (POST /api/v1/card/orders/{draft_id})
  └─ 5. 多渠道支付流转 (支持微信、支付宝、抖音、美团等)
```

### Skill 核心工程考量：
- **零配置无感连接**：在桌面应用中点击“导出办卡 Skill”，即可自动打包生成包含实际动态端口与 `api_key` 的技能包，WorkBuddy 一键导入即可使用，无需人工繁琐配参；
- **防幻觉与状态机容错**：严格限制 Agent 的调用次序，严禁在结果不明或超时情况下重复重试下单/支付，关键扣费环节必须向人类操作员展示 summary 摘要并获得明确授权后才允许写入。

## 🛠️ 两大核心自动化业务子系统

### 1. 会员办卡全链路 RPA 自动化
针对会员办卡的高频流程，底层结合 **CDP（Chrome DevTools Protocol）** 与 **UIA（UI Automation）** 深度驱动：
- **会员与卡种智能检索**：支持按姓名/手机号实时检索已有会员档案，新用户自适应免额外建档接口无感并入；
- **人像二进制检测与照片流上传**：直接流式上传二进制人脸照片，内置人脸合规性校验及重试机制；
- **订单草稿与多渠道核销**：支持生成临时草稿、订单审核状态机判定，以及微信、支付宝、美团、抖音等多达 8 种支付通道核验。

### 2. 停车券动态二维码切码与车牌直发中枢
针对商业体停车优惠发放痛点：
- **一次性动态码无缝轮询切码**：针对“领完即作废”特性，设计 3 秒状态嗅探长轮询池，毫秒级感知码状态并动态重新生成高清二维码图片流，前台大屏无感切码；
- **私有协议逆向与 RSA 免密续期**：逆向复刻官方登录与发券接口，实现 RSA 动态公钥加密通信与 Session 探针自愈机制，解决第三方频繁强制退登的问题；
- **车牌直发与幂等防刷网关**：内置时间窗口幂等锁、自适应指数退避限流与失败工单兜底机制，杜绝恶意刷券。

## 📦 跨端与桌面集成交付（Electron）

- 基于 **Electron** 封装轻量桌面客户端，将 Python 自动化后端与本地服务打包为独立运行环境；
- 支持系统托盘常驻运行、开机自启、服务健康状态感知，并集成**一键复制连接信息**与**一键导出办卡 Skill** 功能，极大降低非技术员工的使用门槛；
- 配置自动化构建管线，实现 Windows NSIS 一键安装与 Mac DMG 双端打包交付。
